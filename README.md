# Lavanya Tours & Travels (OPC) Pvt Ltd — Mysore

> **Your Journey, Our Priority**

A modern, responsive, high-converting travel agency and vehicle rental web application built for **LAVANYA TOURS AND TRAVELS OPC PVT LTD**, based in Mysore (Mysuru), Karnataka.

---

## 🚗 Overview

Lavanya Tours & Travels provides premium vehicle rentals and customized tour travel arrangements across South India and North India:
- **Cars**: Toyota Etios, Toyota Innova, Toyota Innova Crysta
- **Tempo Traveller**: Group transportation for families and excursions
- **Force Urbania**: Premium 12-to-16-seater vehicle options
- **Buses**: 21-Seater buses, options up to 49 seats, and Volvo bus rental enquiries
- **Tours**: Customized travel enquiries for Coorg, Ooty, Mysore, Mangalore, Kodaikanal, Madurai, Coimbatore, and North India circuits

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS 3.4
- **Forms & Validation**: React Hook Form + Zod (`@hookform/resolvers`)
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **SEO & Schema**: OpenGraph, Twitter Cards, Semantic HTML5, and Schema.org `TravelAgency` LocalBusiness JSON-LD

## 🚀 Getting Started

```bash

npm install

# Start development server
npm run dev

# Build for production
npm run build
```
